# Drive Studio

A Google Chrome extension that adds a panel to Google Drive for organizing your files and folders into categories, developed by **Juliano Oliveira / DATACG**.

Categories can have unlimited levels of subcategories. You can drag and drop files, search with filters, add tags and notes, and hide items. The organization is **virtual**: Drive Studio never moves, renames, or deletes anything in your Drive. Items are stored by their Drive ID, so they stay in place even when a file is moved or renamed.

Drive Studio is free. [Get it on the Chrome Web Store](https://chromewebstore.google.com/detail/drive-studio/jkdkipflekoipmflbpnbihfbenjplnpo).

## Privacy

Drive Studio has no server of its own. Your organization is stored in your browser and, if you turn on sync, in a hidden folder of your own Google Drive that only Drive Studio can access. Drive Studio uses only Google's non-sensitive permissions, so it cannot read the other files in your Drive. Read the full [privacy policy](https://datacg.net/drivestudio-privacy/), and learn more at [datacg.net/drivestudio](https://datacg.net/drivestudio/).
